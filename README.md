## Overall Design

Create a clean, modern, professional website that would impress potential employers and recruiters.

Design requirements:

* Professional corporate appearance
* Modern and visually attractive UI
* Responsive on desktop, tablet, and mobile
* Easy navigation
* Smooth scrolling and subtle animations
* Good spacing and typography
* Accessible and easy to read
* Use a professional colour palette with a bright, clean background and strong accent colour
* Do not make the design overly complicated
* Use professional icons where appropriate
* Include hover effects on buttons and project cards
* Make the website look like a real professional portfolio, not a school template
